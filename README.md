# Needle Drop
For my partner's birthday in 2025, I purchased them a record player. After that, we quickly dove into the world of records, quickly amassing nearly 300 records in the year since. This quickly presented a problem to us. How do we remember which records we already bought? What about our wish lists? Are there stats that could be derived from our collection?

**That's the goal of this website.**

Of course we could have used Discogs, but that doesn't track our favorite record stores, our most played albums, or any other stats.

## About this project
This project is written in React, using the following libraries
- React
- MaterialUI
- Supabase
- React Tables
- React Query
- React Hot Toast
- Recharts

This project uses Supabase as the backend and has an accompanying Discord bot located [here](https://github.com/rgero/VinylBot)
